## 📌 Project Overview

**Qema Graduation Project** is the central documentation repository for a graduation project. It contains the full **Software Requirements Specification (SRS)**, design documents, diagrams, and project management artifacts — covering everything from the initial proposal to testing and user documentation.

---

- **Intended Audience & Reading Suggestions** – Document guide

## 🚀 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/AmjadIbrahim1/Qema-Graduation-Project.git
   ```
2. Browse the documents by category (requirements, design, timelines, testing).
3. Open `.docx` files with Microsoft Word or Google Docs, and `.pdf` files with any PDF reader.
4. Extract `.7z` / `.rar` archives to view diagrams (ERD, Use Case).
